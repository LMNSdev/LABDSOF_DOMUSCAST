US-15: identificar o residente pelo nome (QR code partilhado)

Wireframe do primeiro acesso do residente, para acordo da equipa antes da implementação (Sprint B). O token do QR code só é validado no servidor quando o residente envia o nome (POST /identidades {token, nome}), por isso a fração só aparece depois de a identidade ser criada. O residente entra pela câmara ou pelo link domuscast://entrar?t= partilhado pelo administrador (US-01). Todos os campos e botões têm etiqueta para leitor de ecrã.
