# Sprint B Backlog

Este é o **Sprint Backlog** do Sprint B, o subconjunto do [Product Backlog](../backlog.md) que a equipa se compromete a entregar neste sprint, o "Sprint #B backlog" pedido na Fase 3 do Sprint A. Cada item só entra aqui depois de confirmado contra a [Definition of Ready](../sprintA/sprintA.md#definition-of-ready-dor) da equipa. As tarefas de produto cobrem a fatia necessária de ponta a ponta (frontend e backend, quando aplicáveis); não separam a mesma funcionalidade em tarefas independentes por camada. Quando há interface, o campo visual regista o link para o wireframe/mockup/protótipo ou indica que não se aplica. Para o detalhe completo de cada história (descrição, critérios de aceitação, estado de validação), ver o [Product Backlog](../backlog.md#1-product-backlog).
